# Stilez — Portfolio

A self-contained, macOS-desktop-style portfolio site.

- `index.html` — the live website (all content + images embedded; open it directly in a browser).
- `editor.html` — no-code visual editor. Open it, choose **Open site file… → index.html**, make changes, then **Download website** and replace `index.html`.

## Local preview
Just double-click `index.html`.

## Editing flow
1. Open `editor.html` in a browser.
2. Open site file… → select `index.html`.
3. Edit, then Download website (it saves a new `index.html`).
4. Replace the old `index.html` with the new one, commit, and push.
